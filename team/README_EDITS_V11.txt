2030 MYEONGDONG — V11 수정 내역 (V10 기반 최종 수정)
코드 안의 수정 위치는 [V11] 주석으로 표시되어 있습니다.

1. PLAY → 게임 즉시 진입
 - index.html: PLAY 섹션에 가까워지면 game.html을 화면 밖 레이어(#gameLayer)에 미리 불러오고,
   첫 장면을 한 번 그린 뒤(셰이더·버퍼 준비) 멈춰 둡니다. 브라우저가 한가한 시간에만 시작합니다.
 - PLAY를 누르면 0.3초 페이드로 바로 1인칭 거리에 들어가며, 클릭과 동시에 마우스 고정(Pointer Lock)과
   키보드 조작이 켜집니다. 계단을 올라가는 장면과 CLICK TO EXPLORE 화면은 더 나오지 않습니다.
 - 아직 준비가 안 된 경우에만 계단 이미지 위에 짧은 로딩 표시가 나오고, 준비되면 자동으로 진입합니다.
 - 게임 중에는 메인 페이지의 렌더링 루프와 화면 배치가 멈춥니다.

2·3. 게임 속 실제 제품 모델 + 제품 정보 패널 (assets/game/city/game.js, world.js)
 - 01 BRIDGE: 떡볶이 명가 카운터 위 게이트형 기기 (프레임·양면 디스플레이·카메라·상단/하단 조명)
 - 02 스마트 바구니 디스플레이: 올리브영 쇼윈도 받침대 위 바구니 + 앞 테두리에 건 디스플레이
   (본체·화면·다이얼과 보라 링·라임 호출 버튼·후크)
 - 03 EMERGENCY PATH SYSTEM: 교차로 남서쪽 보행 가장자리에 3대가 일정 간격으로 설치된 전개 상태
   (검은 본체·수직 기둥 2개·투명 아크릴 바·보라 LED·양끝 경고 모듈). 최신 PRODUCT01 모델 기준이며 X자 구형 디자인은 쓰지 않습니다.
 - 각 GLB의 치수와 부품 비율을 읽어 만든 Low-poly 모델이고, 원본 GLB는 게임에 넣지 않았습니다.
 - 제품 앞에 가면 조준점이 라임 링으로 바뀌고 "CLICK 또는 E · 제품 정보 보기" 안내가 나옵니다.
 - 패널: 렌더 이미지 · 제품명 · 설치 장소 · 문제 · 해결 방식 · VIEW PRODUCT · 닫기.
   문구는 각 제품 사이트의 내용으로 구성했습니다. 패널이 열려 있는 동안 이동·시점이 멈추고, 닫으면 같은 위치와 시점에서 이어집니다.

4. BACK TO PLAY
 - 게임 왼쪽 위 버튼 이름을 BACK TO PLAY로 바꿨습니다. 누르면 "THE FUTURE IS ALREADY HERE. / PLAY" 섹션으로 돌아갑니다.
   인트로는 다시 나오지 않습니다.
 - 종료 시 렌더 루프 정지, 키 입력 초기화, 마우스 고정 해제를 합니다. 다시 PLAY를 누르면 같은 게임이 재개되어 중복 실행되지 않습니다.
 - game.html을 직접 열었을 때는 index.html?return=play 로 이동합니다.
 - 지도 → 제품 사이트 → 지도 복귀 버튼은 바꾸지 않았습니다.

5. 섹션 배경 전환: 모든 섹션 위아래에 같은 색(#0b0a11)으로 이어지는 그라데이션을 넣었습니다.
   보라 앰비언트 빛은 다음 섹션 위쪽까지 이어지고, 마키·지도 섹션의 직선 경계선은 없앴습니다.

6. 용량: 압축 해제 기준 51.9 MB → 40.0 MB
 - 모델 경량화(KHR_mesh_quantization): 법선과 UV는 정수형, 인덱스는 16비트로 바꿨습니다(오차 0.00002 이하).
   smart-basket/lib/viewer.js에 이 형식을 읽는 코드를 추가했습니다.
 - 글꼴: 사이트에 실제로 쓰인 글자만 남긴 서브셋입니다(파일 이름·형식은 같음).
 - intro_001.mp4: 같은 해상도·프레임·색 정보로 다시 인코딩했습니다(SSIM 0.991).
 - 캐릭터 텍스처: JPEG를 WebP로 바꿨습니다.
 - 오프라인(file://) 실행용 내장 데이터도 같은 모델·글꼴로 다시 만들었습니다.

7. 이동 속도: 걷기 2.15 → 3.12 m/s(1.45배), 달리기(Shift) 4.3 → 6.24 m/s
 - 대각선 정규화, 프레임 독립(dt), 0.12 m 단위로 나눠서 하는 충돌 판정
 - 손을 떼면 약 0.1초 안에 정지하고, 걷기 흔들림 진폭은 3 cm에서 2.4 cm로 줄였습니다.
