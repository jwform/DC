PART 02 — THREE PRODUCTS 카드
오류 원인
1) 카드마다 기본 transform이 달랐음: 양옆 카드는 z=-190px, scale 0.93이 기본값 → 포커스해도 중앙 카드보다 작게 보임
2) CSS transition(box-shadow .4s)이 JS가 매 프레임 바꾸는 글로우 값과 충돌
3) transform-style:preserve-3d가 overflow:hidden·filter와 함께 쓰여 평면화되고 겹침 순서가 불안정
수정
- 세 카드 모두 같은 기본 평면과 크기 사용. 포커스 = scale 1.06 + 앞으로 60px + 선명 + 퍼플 테두리·글로우 (세 카드 동일)
- 카드 컨테이너 전체를 확대 (transform-origin 50% 50%로 통일), 간격 1.12배라 확대해도 서로 겹치지 않음
- 기본·이탈 시 포커스: BRIDGE
- 비활성 카드: 블러 2.2px(모바일 1.4px), 밝기 0.8, 불투명도는 낮추지 않음
- 클릭해도 페이지 이동 없음 (V7 동작 유지). 모바일은 탭하면 포커스 후 BRIDGE로 복귀
